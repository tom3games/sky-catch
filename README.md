# 空中キャッチ

https://tom3games.github.io/sky-catch/

ベランダからうっかり落ちてくる人を、ワイヤーで飛んで空中で受けとめ、救護マットへ運ぶ3Dバカゲー。1回90秒。スマホのブラウザで遊べる。

- 操作: 左スティックで移動、画面（ビル）をタッチでワイヤー、跳ぶボタン。壁に張り付いたらスティックで上下左右に這う（PC: WASD・クリックか E・Space）
- 仕様の正本: `~/Desktop/claudecode/ideas/sky-catch.md`
- 検証: `node verify.mjs`（テスト中は無音）／釣り合い: `node tools/sim.mjs 12`
- 素材と出所: CREDITS.md
